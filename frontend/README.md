# Find Your Nest - Frontend (React + Vite + Tailwind)

This is a ready-to-run frontend for the Find Your Nest project.
It uses Vite + React + Tailwind and ships with a simple in-memory mock API.

## Quick start

1. cd /path/to/findyournest-frontend
2. npm install
3. npm run dev
4. Open http://localhost:3000

Environment:
- .env contains VITE_USE_MOCK=true which enables the mock API.
- To connect to a real backend, set VITE_USE_MOCK=false and VITE_API_BASE_URL to your backend URL.
